# 🧼 Protocolo de Descontaminação de Cache e LocalStorage

Define os passos para limpeza rápida caso haja retenção de rascunhos antigos ou conflitos de porta entre aplicações em `localhost:3000`.

## Passo a Passo
1. **Limpar Armazenamento do Navegador:** Pressione `F12` > Aba `Application` > `Storage` > Clique em `Clear site data`.
2. **Reiniciar Servidor Local:** Parar o processo Node anterior e reiniciar com `npm run dev`.
